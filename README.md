# DecodeLabs Project 2 – Exploratory Data Analysis

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) using Python and Pandas to understand the dataset and identify patterns, trends, distributions, and outliers.

## Objectives

The analysis was carried out to:

- Calculate basic statistics such as count, mean, and median.
- Examine trends and distributions in the data.
- Identify outliers using the IQR method.
- Summarize the key observations from the analysis.

## Tools Used

- Python
- Jupyter Notebook
- Pandas

## Dataset

The analysis uses the dataset provided for DecodeLabs Project 2.

The dataset contains order-related information, including numerical and categorical variables such as `TotalPrice`, `Quantity`, `UnitPrice`, `Product`, `PaymentMethod`, and `OrderStatus`.

## Analysis Performed

The notebook follows these main steps:

1. Load the dataset.
2. Preview and inspect the data.
3. Check for missing values.
4. Calculate count, mean, and median.
5. Examine trends and distributions.
6. Identify outliers using the IQR method.
7. Summarize key observations.
8. Provide a short conclusion.

## Missing Values

The `CouponCode` column contains missing values. These values were left as missing during the exploratory analysis rather than being replaced, as the purpose of this project is to explore and understand the dataset.

## Outlier Analysis

The IQR (Interquartile Range) method was used to identify unusual values in the numerical data, particularly `TotalPrice`.

## Key Outcome

The analysis provides a basic understanding of the dataset's numerical characteristics, trends, distributions, and unusual observations.

## Files Included

- `Decode Labs Project 2 Data Analysis (1).ipynb` – Jupyter Notebook containing the complete analysis.

## Conclusion

This project demonstrates the use of basic exploratory data analysis techniques to understand a dataset. The findings provide a foundation for further analysis as more advanced data analytics skills are introduced.
